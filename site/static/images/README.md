# site/static/images

본인이 직접 추가하는 이미지를 넣는 위치입니다.

이 폴더의 파일은 빌드 시 `public/images/` 로 복사되고,
`.github/pages_build.py` 의 경로 보정이 프로젝트 주소 접두사
(`/assignment001-MyWebPage/`)를 자동으로 붙입니다.
따라서 본문 마크다운에서는 `/images/<파일명>` 형태로 참조하면 됩니다.

주의: 경로 보정은 `public/` 안에 **실제로 존재하는 파일**에만 적용됩니다.
파일을 넣지 않은 채 참조하면 접두사가 붙지 않아 404가 됩니다.

## 현재 필요한 파일

| 파일명                     | 참조 위치                                   | 상태      |
| -------------------------- | ------------------------------------------- | --------- |
| `seedlab-dashboard.png`    | `content/english/blog/post-1.md` 실제 구현 화면 | 투입 대기 |
