##### 학습 목표 및 다음 행동

저의 목표는 프론트엔드와 백엔드를 모두 이해하고,
서비스의 전체 구조를 설계하고 구현할 수 있는 풀스택 개발자로 성장하는 것입니다.

이를 위해 웹 개발의 기본 원리와 데이터 처리 과정을 학습하고,
실제 프로젝트를 통해 프론트엔드와 백엔드가 연동되는 과정을 경험하고 있습니다.

앞으로는 다음과 같은 방향으로 학습을 이어가고자 합니다.

- 프론트엔드와 백엔드의 기술을 함께 활용하는 실습 진행
- 하네스를 도입한 실습을 여러 건 진행하며 개발 및 검증 과정 경험
- 프로젝트에서 발생하는 오류를 직접 분석하고 해결하는 능력 향상
- 새로운 기술을 학습하는 데 그치지 않고 실제 기능 구현에 적용하는 경험 축적

##### 역량 및 실제 사례

풀스택 개발과 프로그래밍 기초를 학습하고 있으며,
수업과 팀 프로젝트를 통해 다양한 기술 직접 활용 경험.

**1. 웹 개발 및 프로그래밍**

- HTML/CSS와 JavaScript를 활용한 웹 페이지 및 기능 구현 경험
- Python과 C를 활용한 프로그래밍 실습 경험
- Git과 GitHub를 이용한 소스 코드 관리 및 프로젝트 협업 경험

**2. IoT 및 데이터 통신**

- Arduino와 Raspberry Pi를 활용한 센서 데이터 수집 및 기기 제어 경험
- MQTT를 이용한 센서 데이터 전달 구조 구현
- RabbitMQ를 포함한 메시지 전달 파이프라인 구성 및 데이터 흐름 검증
- WebSocket 기반 실시간 데이터 전달 및 모니터링 기능 구현 경험

**3. 데이터베이스 및 시스템 연동**

- SQL 및 데이터베이스를 활용한 데이터 관리 경험
- 센서 데이터가 게이트웨이와 서버를 거쳐 데이터베이스에 적재되는 과정 검증
- 실제 기기와 웹 서비스 사이의 데이터 전달 및 통합 동작 확인

**4. 실제 프로젝트 적용 사례**

2026년 1학기 캡스톤 - '종자 증식실 모니터링 시스템'
맡은 역할: IoT 및 실시간 모니터링 파트를 담당했습니다.

Arduino UNO R4 WiFi와 Raspberry Pi를 활용해 센서 데이터를 수집하고, MQTT와 RabbitMQ를 거치는 데이터 파이프라인을 구성했습니다. 또한 WebSocket 기반 실시간 모니터링 기능과 데이터 신선도를 기준으로 센서 연결 상태를 판정하는 기능을 구현했습니다.

실제 센서 데이터가 데이터베이스에 정상적으로 적재되는지 확인했으며, 웹 대시보드에서 정상·주의·미연결 상태와 측정값의 급등·급락을 확인할 수 있도록 구현했습니다. 원격 액추에이터 제어 기능도 실제 기기와 연동하여 동작을 검증했습니다.

이러한 경험을 통해 개별 기술을 사용하는 것뿐 아니라 여러 구성 요소를 연결하고 전체 시스템이 정상적으로 동작하는지 확인하는 과정의 중요성을 배웠습니다.
